## General Objective
This block will go through the validated CSV files generated by Module 4 and execute the required mathematical operations to establish the definitive metrics for each evaluated model within each grammar.
The following metrics will be initially implemented:
### 1. Pass@30
* **Definition:** Determines the potential and maximum capacity of the model to find a correct solution in a wide range of attempts.
* **Calculation:** If, upon "unrolling" all groups belonging to the same query (until covering the 30 executions), at least one (1) of the executions has been evaluated as Correct, the entire query is marked as *Pass*.
### 2. Success Rate
* **Definition:** Represents the reliability of the model, that is, that it generates a semantically correct representation for a given query.
* **Calculation:** For a given query, the number of correct outputs (after unrolling the groups) is divided by the total number of iterations (sum of the quantities of the groups).
### 3. Correct Hypothesis Coverage
* **Definition:** Evaluates how well the model is able to infer and cover the different valid semantic interpretations when faced with a query that is inherently ambiguous.
* **Condition:** It is only applied to queries coming from datasets with multiple confirmed *Ground Truths* (e.g., AMBROSIA).
* **Calculation:** It is obtained by crossing the number manually validated in Module 4 (the count that the Module 3 Evaluator LLM believed to cover, corroborated by the human). General formula: 
    * `Count(Intersection between hypotheses generated by the model and the real ones) / Count(Total real hypotheses)`.
### 4. Significance Testing (Paired Significance Tests)
* Since all representations (SemGIR, SQUALL, GraphQ) are evaluated on exactly the same 200 identical queries (strictly controlling the difficulty of the query), the variables are not independent. 
* **Paired statistical tests** must be performed at the query level to determine the real statistical significance of the improvement of SemGIR compared to the other grammars.
## Persistence
All calculations generated by this script will be dumped unified into global CSV documents ready for graphical analysis.
